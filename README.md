# Sonsuz Çay Molası Simülasyonu

## Bu Proje Nedir?

Bu, insanlığın en büyük icadının (prokrastinasyonun) dijital zirvesidir. Sonsuz Çay Molası Simülasyonu, çayı demlemeyi, içmeyi, yeniden demlemeyi ve "biraz daha oturayım" demeyi sonsuza kadar simüle eder. Gerçekten çalışır. Gerçekten boş durursunuz. Ve bundan gurur duyarsınız.

**Uyari:** Bu programı çalıştırdıktan sonra iş hayatınız, ilişkileriniz ve belki de evrenin kendisi bozulabilir. Sorumluluk kabul etmiyoruz. Çay severiz.

## Özellikler

- Çayı asla bitirmez.
- Rastgele absürt molalar ekler.
- "Bir fincan daha" diyerek ömür tüketir.
- Felsefi çay yorumları yapar (tamamen uydurma).
- Ctrl+C ile durdurulabilir ama neden dursun ki?

## Kullanım

```bash
python3 cay_molasi.py
```

Sonra oturun, izleyin, çay için (gerçek dünyada). Program sizin yerinize boş durur.
